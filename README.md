# آوا — استودیوی گفتار فارسی

یک سامانهٔ راست‌به‌چپ با فونت **Vazirmatn** برای تبدیل متن فارسی به فایل صوتی، قابل میزبانی روی **GitHub Pages**. تولید گفتار با مدل فارسی **Piper / Amir** داخل یک Web Worker انجام می‌شود؛ متن به API یا سرور گفتار ارسال نمی‌شود.

## قابلیت‌ها

- ورود متن یا فایل TXT با کدگذاری UTF-8؛ حداکثر ۱۲۰ هزار نویسه.
- خواندن فارسی ایران با صدای امیر، تنظیم سرعت از ۰٫۷۵ تا ۱٫۲۵ برابر و مکث بین جمله‌ها.
- اصلاح تلفظ با قالب `واژه = تلفظ` و پشتیبانی از اعراب؛ تبدیل عددها به واژه‌های فارسی.
- پردازش بخش‌به‌بخش برای روایت‌های ۳۰ دقیقه‌ای و بیشتر؛ محدودیت مصنوعی ۳۰ دقیقه وجود ندارد. توان پردازشی، حافظه و فضای دستگاه محدودیت عملی هستند.
- ذخیرهٔ اتمی هر بخش PCM و موقعیت تولید در IndexedDB؛ مکث، توقف فوری و ادامه پس از تازه‌سازی صفحه.
- پخش و دانلود WAV یکپارچه، تک‌کاناله، ۱۶ بیت، ۲۲٬۰۵۰ هرتز؛ فایل ۳۰ دقیقه‌ای حدود ۸۰ مگابایت است.
- ذخیرهٔ پیش‌نویس و تنظیمات در مرورگر؛ جلوگیری از تولید هم‌زمان در چند تب در مرورگرهای دارای Web Locks.
- مدل، موتور WASM و فونت از همان میزبان سایت دریافت می‌شوند. کلید API، پایگاه دادهٔ سرور یا اشتراک لازم نیست.

## دقت تلفظ

هیچ مدل گفتاری تلفظ بی‌خطای تمام نام‌ها، کلمات چندخوانشی و جمله‌های مبهم فارسی را تضمین نمی‌کند. این سامانه از یک **مدل فارسی واقعی** استفاده می‌کند و صدای انگلیسی را به جای فارسی پخش نمی‌کند. برای متن حساس یا بلند، ابتدا نمونهٔ کوتاه را بشنوید و با اعراب و اصلاح تلفظ، نتیجه را بازبینی کنید. این مدل در سطح «medium» منتشر شده است؛ صدای استودیویی انسانی یا سرویس تجاری با تضمین کیفیت نیست.

## اجرای محلی

نیازمندی: Node.js 22 یا جدیدتر و اینترنت برای نصب و اولین ساخت.

```sh
npm ci
npm run build
npm run dev
```

نشانی محلی: `http://localhost:4173`. فایل HTML را با `file://` باز نکنید؛ دریافت WASM و مدل به HTTP/HTTPS نیاز دارد. ساخت اول فایل مدل حدود ۶۴ مگابایت را از Hugging Face دریافت می‌کند. نسخه و SHA-256 مدل در `scripts/build.mjs` ثابت و بررسی می‌شوند. ساخت‌های بعدی از کش استفاده می‌کنند. پوشهٔ `dist` شامل تمام دارایی‌های لازم است و به کلید یا درخواست بیرونی هنگام تولید نیاز ندارد.

برای اجرا در مسیر پروژهٔ GitHub Pages، همهٔ مسیرها نسبی هستند. موتور عمداً با یک thread اجرا می‌شود چون Pages هدرهای COOP/COEP را در اختیار برنامه نمی‌گذارد.

## انتشار در GitHub Pages

۱. در مخزن، **Settings → Pages → Build and deployment → Source** را روی **GitHub Actions** بگذارید.

۲. Workflow با نام **Test and publish Avā** با push به `main` اجرا می‌شود. اگر تنظیم Pages را بعد از push انجام داده‌اید، از تب **Actions** همان workflow را با **Run workflow** اجرا کنید.

۳. Workflow آزمون‌ها را اجرا می‌کند، مدل و وابستگی‌های ثابت را می‌سازد و پوشهٔ `dist` را با مجوزهای محدود `pages:write` و `id-token:write` منتشر می‌کند. نتیجهٔ نهایی و نشانی منتشرشده در اجرای workflow دیده می‌شوند.

ابزار اتصال GitHub ممکن است اجازهٔ نوشتن workflow یا تغییر تنظیمات Pages نداشته باشد. در این حالت خطای مجوز باید از طرف مالک حساب حل شود؛ هیچ توکن یا کلیدی داخل کد و تاریخچهٔ Git قرار ندهید.

## آزمون‌ها

```sh
npm test
npx playwright install --with-deps chromium
npm run test:browser
npm run test:voice
# آزمون طولانی با مدل واقعی؛ ممکن است به توان دستگاه زمان زیادی بخواهد:
npm run test:long
```

- آزمون‌های واحد، عددخوانی، مرزهای فارسی، حفظ همهٔ واژه‌ها در متن بلند، و طول RIFF برای فایل نیم‌ساعته را بررسی می‌کنند.
- آزمون‌های رابط، واکنش‌گرایی، بررسی خودکار دسترس‌پذیری، ذخیرهٔ پیش‌نویس، مکث/تازه‌سازی/ادامه و دانلود را می‌سنجند. در آزمون ۳۱ دقیقه‌ای مسیر ذخیره و ترکیب فایل، خروجی موتور عمداً شبیه‌سازی می‌شود؛ این آزمون ارزیابی کیفیت تلفظ نیست.
- `test:voice` مدل فارسی واقعی را اجرا می‌کند و صوت غیرساکت، WAV قابل پخش و نبود درخواست شبکهٔ بیرونی را می‌سنجد. کیفیت تلفظ باید شنیداری بازبینی شود.
- `test:long` با همان مدل واقعی خروجی بیش از ۳۰ دقیقه می‌سازد؛ در CI معمولی به دلیل زمان اجرا فعال نیست.

## نگهداری داده‌ها

پیش‌نویس و آخرین پروژه در **همین مرورگر و همین دستگاه** نگه‌داری می‌شوند. پاک کردن داده‌های سایت یا تخلیهٔ خودکار فضای مرورگر می‌تواند آن‌ها را حذف کند. برای نگهداری دائمی، WAV را دانلود کنید. در زمان ساخت طولانی، تب را باز و دستگاه را روشن نگه دارید. برنامه در صورت امکان از Screen Wake Lock استفاده می‌کند، اما بسته شدن سیستم یا توقف مرورگر قابل جلوگیری قطعی نیست.

مرورگرهای جدید Chrome و Edge روی رایانه برای متن‌های طولانی مناسب‌ترند. سرعت تولید با سرعت پخش متفاوت است و به CPU و حافظه بستگی دارد. در اولین استفاده حدود ۹۰ مگابایت دریافت انجام می‌شود؛ مدل در صورت اجازهٔ مرورگر کش می‌شود. کارکرد کامل آفلاین پس از بستن مرورگر تضمین نشده است.

## ساختار

`src/text.mjs`: آماده‌سازی و بخش‌بندی فارسی؛ `src/worker.js`: آوانویسی و ONNX؛ `src/storage.mjs`: ذخیره و بازیابی اتمی؛ `src/audio.mjs`: WAV؛ `src/app.mjs`: رابط؛ `scripts/build.mjs`: بسته‌بندی مستقل؛ `.github/workflows/pages.yml`: آزمون و انتشار.
